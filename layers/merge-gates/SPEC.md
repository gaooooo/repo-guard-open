# 合并门禁 · 规范（汇报稿）

来源：references/00-gate-index.md。非 ReAct，卡的是进主干。

全部阻断级，不通过即不可交付。模型只读取结论，不读取检查项与阈值。

| ID | 意图 | 途径 |
|---|---|---|
| G-01 | 构建成功、无告警，依赖锁定与声明一致 | 流水线 |
| G-02 | 测试全部通过、竞态检测通过、覆盖率达阈值 | 流水线 |
| G-03 | 格式化零差异、静态检查零告警 | 流水线 |
| G-04 | 单次变更规模、新增重复、未引用代码、新增依赖均不超上限 | 流水线 |
| G-05 | 无凭据泄露，SAST 无高危 | 安全扫描 |
| G-06 | 依赖无高危漏洞、许可证合规、SBOM 已产出 | 安全扫描 |
| G-07 | 分支与提交规范、独立评审人、门禁未过不得合入、受保护历史未改写 | 代码托管 |

## 纪律（00 原文）

- 未取得结论 → 视为未通过；禁止预测
- 未通过 → 修源头；禁止改判据、调阈值、加抑制、加 skip
- G-04 只测量体量，测不出过度设计；语义自查仍走 01 与 15§九
- 插件给 CI 片段与 permissions.ask 示例，强制不了宿主
