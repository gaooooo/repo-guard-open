# 工程事实 · 规范（汇报稿）

来源：08 配置与多环境、10 工程文档、05 环境隔离寻址、15§二 假设显式化。

## 收什么

- 公共层目录、组件库包名、行数上限（repo-facts）
- 环境分层标识、非生产不得指向生产资源所依赖的生产资源清单路径
- 契约 / 架构 / 设计稿的权威源路径（只写路径，不贴正文）
- 数据分级表的权威位置
- 模块专属短事实（代码读不出来的）

## 不收什么

- 操作步骤（技能库）
- 符号禁令（红线）
- 「必须先查 impact」（过程门禁）
- 「意图不清时问人」的条款正文（人审）。机器文件暂寄在 facts.json 的 stopConditions，不要写进 redlines.json。

## 条款（汇报级）

1. 事实必须可溯源到文件或配置；推断必须标明为推断。
2. 「未查到」不得写成「不存在」。
3. 短句进 CODEBUDDY.md；按路径进 rules；大块语料只给路径。
4. 公共层清单必须人过一眼，禁止只靠目录惯例自动拦。

## 落点

CODEBUDDY.md（T3）· .codebuddy/rules/*.md（T6）· repo-facts.json
