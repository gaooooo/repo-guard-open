# 过程门禁 · 规范（汇报稿）

来源：03 最小改动与影响面、11/15 证据与诚实、15§二～§八 执行纪律。
范围：ReAct 内、机器拍板。不是 CI。

## 默认开（核心）

- 改公共层已有文件，本轮未查 impact → deny

## 默认关（后续按治理数据打开）

1. 最小改动：禁止功能变更夹带重构与格式（03）
2. 改动范围声明与事后比对（15§七）
3. 循环：重复调用 / 连续失败 / 同文件写失败（15§八）
4. 未跑验证不得写「已测/已通过」（15§三、11）
5. 新建页/组件强制 similar、hot、lib search（15§九 复用）
6. Stop 交付提醒（12）；不硬拦 git commit

## 明确不做

- 预测或代替 G-01～G-07
- 在 hook 里建图
- 把 lint 失败写成 Stop 硬拦（那是合并门禁）
