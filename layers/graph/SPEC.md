# 图谱 · 规范（汇报稿）

来源：03 影响面清单、04 从调用点反推契约、06 超时拓扑、01/15 检索既有实现。
图谱是代码现算，不是规范原文。

## 何时必须查图

1. 改公共层已有文件 → impact（核心，过程门禁硬要求）
2. 新建页面 → similar；新建组件 → hot / lib search
3. 改对外接口 → 调用点与出入参（contracts / trace）
4. 评估超时/重试是否倒挂 → 依赖边；图不全必须明说暂不支持

## 纪律

- hook 内禁止建图；缓存 miss fail-open
- 空图不得当成「没有调用方」
- 必须输出盲区（动态 import、SQL、样式、跨服务）
- 「未查到 ≠ 不存在」
