# repo-guard

> 仓库体检与影响面守卫。**零服务端**——不连任何服务、不需要令牌，图谱从本仓代码现算并缓存本地，规则读仓库文件。

装完之后 AI 会做三件它以前不做的事：改公共层代码**之前**先确认影响面、写完超长文件会被提醒、想绕道用 `sed` 写公共层会被记一笔。

---

## 装完之后做什么

### 1. 跑一次体检

```bash
repo-guard init
```

它会告诉你：这个仓是什么技术栈、多少文件超行数上限、有没有循环依赖、检查命令和流水线缺哪几步、以及**推测的公共层目录和推测依据**。

**一个字节都不会写。** 想生成配置再加 `--write`。

### 2. 确认公共层，生成配置

```bash
repo-guard init --write
```

生成 `.codebuddy/repo-facts.json`（公共层清单、行数上限），并往 `.gitignore` 追加缓存目录。

⚠️ **公共层是推测出来的，一定要人过一眼。** 各仓目录约定不一样，猜错要么漏拦、要么天天误伤——后者会让人直接卸载。打开 `repo-facts.json` 改 `publicLayer` 即可。

### 3. （可选）配红线

配完跑一次 `repo-guard audit` —— 它会告诉你规则有没有腐烂。


`.codebuddy/redlines.json`：

```json
{ "rules": [
  { "id": "RL-001",
    "paths": ["src/api/**"],
    "rule": "这个接口有外部调用方，改名等于让对方 404",
    "confirmed": true }
] }
```

红线是**人写的意图**，代码里读不出来（"外部仍有调用方"静态分析推不出来），所以必须进 git，跟代码走同一个 PR。

⚠️ **手写的规则会腐烂，而且人 review 发现不了。** reviewer 能判断「这条该不该加」，但验证不了「paths 写全了没」「evidence 行号还准不准」「protects 的符号是不是早就改名了」。所以配完红线要跑 `audit`：

```
✗ RL-001  上链状态字段不能删
    有 1 处出现位置不在声明的 paths 内 —— 这些位置是后门，agent 在那里改动不会被拦
      ⚠ src/common/chain.ts:1
      建议补进 paths: src/common/*.ts
✗ RL-002  这个常量不能改名
    受保护标识符在代码与 SQL 里都找不到 —— 这条红线在守空气，应删除或更正
```

**人写意图，机器验完整性。**

### 4. 重开会话

插件在会话启动时加载，**必须重开会话才生效**。

## 命令

| 命令 | 干什么 |
|---|---|
| `init [--write]` | 体检 + 生成配置 |
| `scan` | 体量与结构：超长文件、循环依赖。**有问题非零退出**，可挂 CI |
| `check <文件…>` | 改动自查：碰没碰公共层和红线 |
| `impact <文件>` | 改它会波及哪些入口 |
| `hot [--limit N]` | 高扇入热点，写新组件前看有没有现成的 |
| `trace <路径>` | 这个页面/接口打到哪里：入口 → 处理函数 → 下游 → 后端接口，**含从调用点反推的出入参** |
| `similar <要做什么>` | 这类页面本仓已经怎么写了，返回同类页骨架 |
| `lib search <要什么>` | 本仓 UI 组件库里有没有现成的 |
| `contracts [接口]` | 反推导出接口类型草稿（**必须人工 review，不能当已有类型**） |
| `audit` | **红线体检**：规则在不在守空气、paths 有没有后门、evidence 还准不准 |
| `governance` | 治理留痕报表：这些门在做有用功还是在骚扰人 |
| `guard init [--write]` | 铺开协作全景七道门的配置骨架（全部默认关，尚未接进运行时） |
| `mcp` | 作为 stdio MCP 给 AI 用（宿主自动拉起，不用手动跑） |
| `hook <name>` | 插件钩子（宿主调用） |

挂进流水线：

```bash
repo-guard scan || exit 1
```

## 它拦什么、不拦什么

| 行为 | 结果 |
|---|---|
| 改公共层**已有**文件，本轮没查过影响面 | **拒绝**，并告诉它去调哪个工具 |
| 改公共层文件，已经查过影响面 | 放行 |
| **新建**公共层文件 | 放行 |
| 改普通业务文件 | 放行 |
| 写完的文件超过行数上限 | 提醒，不拒绝 |
| 用 `sed`、重定向等写公共层 | 提醒 + 计数，**不拒绝**（拦 shell 误伤率太高） |
| 本仓还没跑过 `init` | **全部放行**，并在会话开始时说明守卫未生效 |

最后一条是有意的：**没有配置就不拦**，绝不能因为工具没配好就把人挡在外面。

## 自检

```bash
node bin/verify-hooks.mjs
```

自建临时仓库跑 20 条用例，覆盖拦截、放行、路径归一、不误伤同名前缀目录、未配置时 fail-open、坏输入不崩。**不碰任何真实仓库。**

改过钩子逻辑就跑一遍——证明「拦得对」容易，证明「不误伤」才是难的。

## 从源码构建

这个插件是**源码版**：`bin/repo-guard` 是构建产物，源码在 `src/`。

```bash
npm install
npm run check      # 改完只需要跑这一条
```

`npm run check` 按序做四件事，任一失败即停：类型检查 → 打包（含冒烟）→ 20 条钩子回归 → 69 条与旧产物的逐字节比对。

只跑 `npm run build` 不够 —— 它只保证产物能跑起来，不保证行为没漂。

| 目录 | 是什么 |
|---|---|
| `src/engine/` | 图谱分析引擎。从 deerclaw 逐字移植，**禁止重构**，改动纪律见 `src/engine/PORTING.md` |
| `src/runtime/` | 仓库定位、配置读写、图谱缓存、会话状态、埋点 |
| `src/cli/` `src/hooks/` `src/mcp/` | 三个入口。共用一个二进制，因为它们要共享图谱缓存与会话状态 |
| `build/` | 构建脚本 + `baseline/`（改造前的产物，逐字节比对的黄金样本，**不能删**） |
| `templates/guard/` | 协作全景七道门的配置骨架，全部默认关 |

完整构建说明见 [`docs/BUILD.md`](docs/BUILD.md)，设计与控制点映射见 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 影响面是怎么算的

```
① 直接调用者 —— 图谱里谁调了它
② 沿反向依赖走，最多 3 跳
③ 落到入口上：处理文件在传播集里，或处理函数直接调了目标
```

打分：`分数 = 上一跳 × 边权 × 0.6`，多路径取最强。

| 边类型 | 权重 |
|---|---|
| 函数调用 / JSX 引用 | 1.0 |
| 继承 | 0.9 |
| 调后端接口 | 0.6 |
| 模块 import | 0.5（import 了不代表真用了） |

**≥ 0.5 算强影响**：直接调用 `1.0×0.6=0.6` 过线，两跳 import 约 0.09 不过线。

> ⚠️ **影响面为 0 不等于可以删。** 每次查询都附盲区清单——动态 import、样式引用、运行时拼接的路径都看不见；SQL、离线任务、其它服务完全在图谱之外。

## 图谱缓存

存 `.codebuddy/.cache/`，`init --write` 会自动加进 `.gitignore`。

**什么时候重建**（两条判据都会触发）：

- git HEAD 变了 —— 切分支、拉新代码
- **源文件最大 mtime 变了** —— 管的是"改了还没提交"

第二条很重要：你刚改完还没提交时，图谱必须跟着更新，否则查出来的是旧答案。

图谱是代码的**投影**，删了重跑结果一模一样，所以不进 git、不用备份。红线不一样——那是人写的意图，丢了就永久损失。

## 支持的技术栈

前端（React / Vue）· Node / TypeScript · Go（Gin、tRPC）· Java（Spring）· Python

**所有分析器置信度都不够时，明确报「暂不支持这个技术栈」，不给空图。**
空图是最坏的失败模式：AI 会把"没有调用者"当成事实去删。

## 运行要求

机器上有 Node 18+。引擎已打包进 `bin/repo-guard`（约 840 KB 单文件），**没有任何外部依赖，不装 npm 包、不下载东西、内网可用**。

只在两处会起子进程，都是可选的：`git`（读 HEAD 做缓存新鲜度判断，没有就退到只看文件 mtime）、`python3`（Python 仓的分析器，没有就只是 Python 仓建不出图）。

**零出网**：产物里没有 `node:http(s)`、没有 `fetch`、没有任何真实 URL，也不读任何令牌。
