# 护栏模式输出约定（草稿，未启用）

## 区分"事实"与"推断"

每个结论都要能追到来源：

- 工具给的 → 写明哪个工具、哪个文件的哪一行
- 读代码得出的 → 说"读 `x.ts:12` 得出"
- 猜的 → **明确说这是猜的**

## 三句不许说的话

| 不许说 | 改成 |
|---|---|
| "已验证 / 已测试通过" | "静态分析显示…，未实际运行" |
| "没有影响" | "图谱里未发现调用者；盲区见下" |
| "这个类型已经有了"（指 `contracts` 的输出） | "这是从调用点反推的草稿，需人工核对" |

## 盲区不许消化掉

工具输出里带的盲区清单要原样传给人，不要总结、不要省略。
它防的是"影响面为 0 所以可以删"这个最危险的推理。
